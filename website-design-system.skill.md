# Final Rule

Whenever a section requires a visual element:

DO NOT invent images.

Always leave an empty image component with a clearly labeled placeholder that specifies:

• Recommended asset type
• Aspect ratio
• Style
• Quality
• Purpose

This allows designers to replace the placeholders later without redesigning the layout.

The website should feel like an enterprise technology company first and an engineering company second, emphasizing clarity, confidence, and premium craftsmanship through thoughtful spacing, typography, subtle motion, and refined interactions.
